# Fatturare

### Effortless Invoicing for Bulgarian Businesses

Fatturare is a native-feel desktop application designed to simplify the complex world of Bulgarian VAT-compliant invoicing. Built with heart and precision, it provides a clean, professional workspace for managing your business paperwork without the clutter.

---

## Core Features

### Multi-Language by Design
Break down borders with seamless switching between Bulgarian and English. Whether you're billing locally or internationally, your interface and documents speak the right language.

### Intelligent Multi-Currency Support
Manage bank accounts across different currencies with ease. Fatturare tracks your IBANs and BICs, ensuring that the right payment details are always attached to the right invoice.

### Native Multi-Platform Foundation
While crafted with a focus on the macOS experience, the underlying architecture provides a fast, responsive, and reliable environment that feels at home on your desktop.

### Streamlined Workflows
From Proforma Invoices to Credit Notes, the workflow is designed to be "easy working." Features like the integrated VAT Calculator (Gross/Net) ensure accuracy with minimal effort.

## Building & Development

Fatturare is built using Electron, React, and Vite. To get started with the source:

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Launch Development Environment**
   ```bash
   npm run dev
   ```

3. **Produce Distribution Build**
   ```bash
   npm run build
   ```

Detailed configuration for the build process can be found in `package.json`.
