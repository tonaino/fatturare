# Fatturare

### Effortless Invoicing for Modern Businesses

Fatturare is a native-feel desktop application designed to streamline the invoicing process for professionals and small businesses. Built with heart and precision, it provides a clean, professional workspace to manage your billing lifecycle with speed and reliability.

---

## Core Features

### Universal Invoicing & Templating
Fatturare makes creating Invoices, Credit Notes, and Proforma Invoices simple and intuitive. With a focus on clean design, the application handles complex document numbering and templating automatically, allowing you to focus on your work.

### On-the-Fly PDF Generation
Generate beautiful, professional PDF documents instantly. Whether you're sending an urgent invoice or archiving records, our high-speed generation engine ensures your documents are ready when you are.

### Highly Customizable Architecture
While originally optimized for the Bulgarian market and its specific VAT requirements, Fatturare is designed to be easily adapted. Its flexible configuration allows for effortless customization of tax rules, document formats, and localization needs.

### Intelligent Multi-Currency Support
Manage bank accounts across different currencies with ease. Fatturare tracks your payment details, ensuring that the correct IBANs and BICs are always perfectly matched to your documents.

### Seamless Multi-Language Support
Break down borders with full support for bilingual environments. Switch between languages effortlessly to cater to both local and international clients.

## Building & Development

Fatturare is built using Electron, React, and Vite. To get started with the source:

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Launch Development Environment**
   ```bash
   npm run dev
   ```

3. **Produce Distribution Build**
   ```bash
   npm run build
   ```

Detailed configuration for the build process can be found in `package.json`.
